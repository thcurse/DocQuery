# Orion API 运维手册

## 连接配置

Orion 网关的生产请求超时必须设置为 18 秒，连接池空闲连接上限为 24。配置项 `orion.http.retry.maxAttempts` 的生产值为 2；它表示首次请求失败后最多再尝试两次。批量导入接口不得自动重试，因为重复提交可能创建重复业务任务。

## 错误码 OX-204

错误码 `OX-204` 表示租约已由其他工作节点持有。处理人员应先读取响应头 `X-Orion-Lease-Until`，等租约到期后重新提交；不得手工删除数据库中的租约行。若连续三次收到 `OX-204`，应检查调用方是否复用了过期的 workerId。

## 错误码 OX-517

错误码 `OX-517` 表示下游签名时间偏差超过允许范围。Orion 允许的时钟偏差为正负 45 秒。应先同步系统时钟，再重新签名请求；轮换密钥不能修复时钟偏差。

## 灰度发布

灰度实例比例先设为 10%，观察 20 分钟且错误率低于 0.8% 后才可扩大到 50%。达到 50% 后至少再观察 30 分钟，才能完成全量发布。任何阶段出现数据重复写入都必须立即回滚，不等待错误率阈值。

## 日志保护

应用日志可以记录 requestId、workerId 摘要和错误码，不得记录 Authorization、完整签名、请求正文中的客户资料或原始幂等键。
