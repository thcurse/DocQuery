# Vue 前端迁移记录与验收清单

## 交付内容

Vue 3 + TypeScript + Vite + pnpm，Naive UI 浅色工作台，Pinia 身份与布局状态，Vue Query 普通资源缓存。后端业务 API、数据库及文档处理逻辑不变。

| 功能 | 迁移内容 | 验证方式 |
| --- | --- | --- |
| 登录与权限 | CSRF、会话恢复、退出、平台/租户路由隔离 | 请求层和身份单测；模拟 API 浏览器检查 |
| 租户与管理员 | 创建、修改名称、启停、新增管理员、重置密码、最后一个有效管理员保护 | 页面检查；真实核心脚本待依赖环境运行 |
| 应用与凭证 | 创建、编辑、启停、凭证创建/撤销、一次性展示、手动复制及保存确认 | 凭证组件单测、浏览器交互 |
| 知识库与授权 | 卡片列表、筛选、创建、编辑、启停、双向授权配置与撤销 | 页面检查、授权弹窗交互 |
| 文档 | 筛选、上传、状态轮询、版本分页、任务详情、重建、处理重试、删除和删除重试 | multipart 请求单测；浏览器上传/重建/历史页刷新 |
| 问答与调试 | 应用读取授权过滤、单轮请求、引用、原文检索、上下文头、幂等键、JSON 复制 | 请求单测、浏览器成功/失败重试、离页取消 |
| 审计 | 筛选、分页、调用标识、详情、执行结果与计数 | 页面检查；真实审计链路待依赖环境运行 |
| 使用说明 | 接入步骤、curl/Java 示例、错误处理、OpenAPI/Postman 下载 | 静态文件单测及浏览器下载检查 |
| 响应式 | 224px 可折叠侧栏、小屏抽屉、表格局部滚动、引用抽屉 | 1440 / 1024 / 390px 截图与页面溢出断言 |
| 发布 | pnpm 锁文件、后端独立构建、Nginx 静态托管与 API 代理 | 前端构建、后端打包；Nginx 实际运行待环境验证 |

接口实现按认证、租户、应用、授权、知识库、文档和查询模块拆分；`api/client.ts` 保留统一导出，原请求层安全断言继续适用。没有新增业务 API 或迁移表。
