# N5.3-A2 Answer Agent v2 复评

> 状态：`COMPLETED_FAILED_ACCEPTANCE`

## 1. 范围与边界

- 沿用 N5.3-A1 冻结的 20 道公开原题、20 份不同文档和人工验收线；
- 真实调用 `/answer`，固定 `HYBRID`、`topK=10`，不传 `documentIds`；
- 采用模型自主决定工具调用的 Answer Agent v2；
- 不替换失败题，不执行剩余 60 题，不开始下一阶段。

## 2. Agent v2

- 模型先接收问题与工具定义，首个有效动作必须是 `searchDocuments`；
- 后续由模型根据已有证据决定继续检索、改写查询、读取章节/原文或结束回答；
- 重复工具参数命中会话内缓存；无效参数作为工具结果返回，不立即中止整个任务；
- 硬断路器固定为最多 10 个工具轮次、20 次工具调用、12 次常规模型调用和 180 秒；
- 最终结构化输出最多修复 2 次；引用约束按段落或列表项执行。

## 3. 真实执行与审计

- 20/20 个逻辑请求 HTTP 200，0 次重试、0 次降级；
- 17 个 `ANSWERED`，3 个 `INSUFFICIENT_EVIDENCE`；
- 共 123 个工具轮次、175 次工具调用、156 次模型调用和 246,588 个登记 canonical 字符；
- 端到端延迟 P50 13,269 ms、P95 34,564 ms、最大 37,767 ms；
- 当前 Answer 契约仍不返回 Token 或费用，精确成本为 `NOT_AVAILABLE_IN_CURRENT_ANSWER_CONTRACT`。

## 4. 质量结果

- 自动参考答案匹配 6/20；
- 正确来源文档引用 17/20；
- 任意冻结 Gold 物理页引用 14/20，Gold 页覆盖率 0.5667；
- PDF 原页人工复核后正确答案 10/20；
- 2 题引用未支持题目要求的关系；
- 数据集问题包括 1 个错误参考答案、1 个错误 Gold 页、1 个不完整 Gold 页和 1 个没有有效选项的问题。

与 A1 相比，HTTP 成功由 10/20 提升到 20/20，正确来源文档引用由 8/20 提升到 17/20，任意 Gold 页引用由 7/20 提升到 14/20。执行可靠性和取证覆盖已明显改善，但答案正确性只有 10/20，未达到 14/20。

## 5. 验收结论

验收结果为 `FAILED`：

- 人工正确答案 10/20，要求至少 14/20；
- 正确来源文档引用 17/20，达到要求；
- 任意 Gold 页引用 14/20，达到要求；
- 无依据引用 2，要求为 0。

主要剩余问题不再是链路频繁报错，而是证据推理质量：选错表格中的对应项、漏项、未执行求和、用相关但不完整的页面回答，以及对矛盾选项缺乏拒答判断。该结果不授权执行剩余 60 题或开始后续阶段。
