## 4. 诊断结论

PackyAPI Responses、Tool Calling 续接和最终 JSON 已恢复，HTTP 可靠性不是本轮阻塞点。
当前失败是两类混合问题：

1. **停止策略过度保守**：模型在只进行 1—2 个工具轮次时即可直接返回证据不足，即使
   初始检索已经包含正确文档或 Gold 页；现有“reasonable attempts”只是 Prompt 文本，
   Java 没有可机械验证的最小取证条件。
2. **章节选择与完整性判断不足**：同名章节可能选错；数字题可能找到局部值却没有继续读取
   对应页或完成明确算术。

因此不能把问题归结为 DeepDoc，也不能只靠扩大上下文解决。当前工具已经能够返回检索证据
文本、`sectionRef` 和完整章节；真正缺少的是 Agent 对“何时可拒答、何时必须继续读”的可控
状态约束，以及同名候选的比较策略。

## 5. 阶段边界

本轮定向复验失败，不继续执行原 20 题 Answer PILOT。下一步应先讨论并冻结一个最小修正，
不得继续无边界增加工具或重做检索架构。修正后仍只复验这 5 题；达到可接受结果后再决定
是否运行 20 题。
