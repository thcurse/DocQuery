# N5.3-A5 PackyAPI 模型供应商替换

> 状态：`RESPONSES_IMPLEMENTED / REAL_PROTOCOL_SMOKE_PASSED / RUNTIME_ACTIVATED`

## 1. 替换范围

- 检索卡生成：DeepSeek `deepseek-v4-flash` 改为 PackyAPI `grok-4.6`；
- Answer Agent：使用同一 PackyAPI Chat Model；
- 导航与查询 Embedding：继续使用百炼 `qwen3.7-text-embedding`，不变；
- 本机 OpenAI 兼容 Base URL：`https://slb-v1.api.fan/v1`；
- Java 仍控制工具执行、权限、预算、证据登记和引用校验。

用户口述的目标是 `grok-5.6`，但本机最终配置和 PackyAPI 模型列表中的实际模型 ID 是
`grok-4.6`，列表中没有 `grok-5.6`。本阶段所有通过结论均只对应实际调用的 `grok-4.6`。

PackyAPI 的 GPT 路线首次真实请求明确返回 `gpt-5.6-luna` 不支持 Chat Completions。项目已改用
LangChain4j 1.16.2 原生 `OpenAiResponsesChatModel`，请求路径为 `/v1/responses`，不升级
LangChain4j，也不改变 DocQuery 的 Java Agent 与工具执行边界。

## 2. 兼容与安全处理

- 移除 DeepSeek 私有的 `thinking.type=disabled` 请求参数；
- 新检索产物写入 `chatProvider=PACKY_API`、`chatProtocol=RESPONSES`、
  `thinkingMode=PROVIDER_DEFAULT`；
- 旧产物的 `DEEPSEEK / DISABLED` 元数据继续只读兼容，现有 100 份文档不会因代码升级失效；
- 供应商、协议、模型和思考模式进入生成指纹，未来主动重建会生成新的不可变检索产物；
- API Key 只允许保存在 `config/application-secrets.yml` 或 `PACKY_API_KEY` 环境变量中；
- 原 DeepSeek Key 已由用户替换为 PackyAPI Key；`grok-4.6` 新版后端已于 2026-08-24
  在 8080 启动。

## 3. 暂定资源边界

PackyAPI 公开接入文档没有给出该模型的精确上下文长度。为避免沿用 V4 Flash 的 1M
假设，检索卡单次原文和 Answer 整轮 canonical 原文预算暂定为 180,000 估算 Token。
这是请求安全上限，不是章节切块或导航子分区阈值。待真实协议冒烟或模型页证据确认后，
才能决定是否调整。

## 5. GPT 路线失败历史

用户随后明确授权一次最小真实协议冒烟。第一次 Chat Completions 在模型生成前被 PackyAPI
以 `region_restricted` 拒绝：`gpt-5.6-luna` 对当前地区不可用；因此工具调用和第二次最终
JSON 请求均未发生。模型列表可枚举不等于模型可调用。当前 PackyAPI Key 还能枚举
`gpt-5.4`、`gpt-5.4-mini`、`gpt-5.5`、`gpt-5.6-sol` 和 `gpt-5.6-terra`，但这些候选
尚未逐个调用，不得声称可用。

用户修改 Base URL 为 `https://slb-v1.api.fan/v1` 后再次授权测试。Chat Completions 返回
`protocol_not_supported`，证明该模型只接受 Responses API。源码切换 Responses 并通过本地
回归后，真实 `/responses` 请求被 PackyAPI 以“请使用标准 Codex 客户端、禁止基于该 API
二次分发或 API 转接”拒绝。该结果说明当前 Key/令牌分组是 Codex 客户端专用，不允许
DocQuery 服务端接入；请求仍在工具调用和内容生成前终止。

## 6. 当前生效边界

1. 当前 Base URL 为 `https://slb-v1.api.fan/v1`，模型为 `grok-4.6`，协议为 Responses；
2. 现有 100 份 READY 文档及其不可变检索产物不自动重建，继续只读兼容；
3. 后续新入库或用户主动重建的文档才使用 PackyAPI `grok-4.6`；
4. 本次不继续运行真实 `/answer` 质量评测，也不据此声称缓存、成本或 Answer 效果达标。
