## 1. 目标

让租户管理员能够对 READY 文档复用已经保存的原始文件，创建一次受控重建候选，并通过正常异步入库链路重新执行 DeepDoc、Canonical、检索卡、导航子分区、Embedding、双索引投影和版本激活。

普通“上传新版本”仍拒绝内容完全相同的文件；同文件重建只能通过独立管理命令发起，不能伪装成内容更新。

## 2. P2-A 冻结范围

- 文档详情页增加按钮 `重建`，不使用“按当前配置重建”等名称；
- 确认框说明复用原始文件、执行完整链路、可能产生供应商费用、旧版本继续可用；
- 仅当前租户的租户管理员可以发起；
- 只允许 ACTIVE 文档且存在 READY activeVersion；
- 同一文档已有 PROCESSING 候选时拒绝，保证最多一个处理中候选；
- 系统流式复制原始对象到新的不可变对象键，原始文件内容、大小和 SHA-256 必须保持一致；
- 创建递增版本号、ProcessingJob 和 Outbox，处理成功前不修改 activeVersion；
- 全链路成功后沿用既有原子激活规则切换；失败时旧 activeVersion 继续服务；
- 管理命令支持 Tenant 范围幂等，重放不产生重复版本或孤立对象；
- 不提供批量重建，不自动重建其他文档；
- P2-A 只执行 Fake Gateway、单元和集成回归，不调用真实 DeepDoc、DeepSeek 或百炼。

管理接口冻结为：

```http
POST /api/admin/v1/tenants/{tenantId}/knowledge-bases/{knowledgeBaseId}/documents/{documentId}/rebuild
Idempotency-Key: <visible ASCII, 1..128>
```

成功返回既有 `DocumentUploadAcceptedVO`，HTTP `202 Accepted`。

前端确认框：

- 标题：`确认重建该文档？`
- 提示：`系统将复用原始文件，重新解析并生成检索数据，可能产生供应商费用。重建期间当前版本继续可用，成功后自动切换。`
- 操作：`取消`、`确认重建`

## 4. P2-B 验收点

1. 两份文档均通过正常队列进入 READY，旧版本在成功前持续可检索；
2. 新版本原始文件 SHA-256 与各自旧活动版本相同；
3. Canonical 标题树不写入派生导航标题；
4. Retrieval Artifact 使用 schema v2；

## 6. P2-A 实现结果

- 管理端新增独立 `POST .../{documentId}/rebuild` 命令，使用 Tenant 范围 `Idempotency-Key`，不接收文件正文；
- 重建前校验 ACTIVE 文档、READY activeVersion 和无 PROCESSING 候选；
- 原始对象通过流式读取复制到新的不可变对象键，文件名、格式、Bucket、大小、SHA-256 和 Content-Type 必须与活动版本一致；
- 接受命令时锁定文档并再次校验活动版本和候选状态，创建递增版本、ProcessingJob 和 Outbox，只更新 latestVersion；
- 幂等重放不重复复制对象或创建版本；并发竞争或校验失败产生的未引用副本会被安全清理；
- 旧 activeVersion 在新版本处理期间保持不变，既有完整处理链路成功后才原子切换；
- 文档详情页新增 `重建` 按钮和冻结的费用提示，不提供批量入口。

## 10. P2-B 长上下文修正

用户明确要求保留所有真实标题，并对固定 64K 阈值和模型生成导航分区提出质量担忧。结合 DeepSeek V4 Flash 官方 1M-token 上下文，冻结并实施以下修正：

- DeepDoc 细粒度 Evidence 块保持不变；适配层仅重组层级编号与高置信标题短语：同页同一水平行、编号在左且间距受控时合并；同一行逆序返回时恢复编号在前；标题与正文粘在同一块时只拆出高置信标题首句。普通 `1.` 列表、跨行候选和标题形态不足的正文不提升；
- 检索卡仍按全部 canonical 真实标题生成，不因内容长度删除真实标题；
- 正式链路默认关闭实验性导航子分区，不再以 64K 作为自动生成条件；P1 schema v2 和兼容读取能力保留，但只有显式实验配置才能启用；
- 单次原文限制由 256,000 UTF-16 字符改为 800,000 估算 token。该值是为 1M 上下文预留系统提示、JSON 输出和估算误差的运行安全预算，不是语义分区阈值；
- 只有原文真正超过 800K 安全预算时才使用内存临时归约；Document 24 的约 130K-token `OVERVIEW` 应直接一次送入模型；
- token 安全预算和导航分区开关进入 generation fingerprint，配置变化必须产生不同派生版本指纹；
- 修正代码先完成免费回归，历史 Version 117 不自动变更；后续真实重建结果见第 11 节。
