# DocQuery N2 检索与回答评测问题清单

> 状态：问题清单 v0.1；不是当前实现范围或 N2.3 验收条件  
> 日期：2026-08-05  
> 关联设计：[`N2.3 文档解析与标准化`](./N2.3-文档解析与标准化.md)、[`N2.4 检索卡与导航向量`](./N2.4-检索卡与导航向量.md)

## 使用方式

本清单只积累少量值得验证的产品问题。等 N2.5/N3 的检索与回答链路完成后，再为每个问题各准备少量代表性文档、查询和期望证据，不在当前阶段扩展成大型评测工程。

## 首批问题

1. 只有文档标题、没有章节标题的长 PDF 只能生成根节点检索卡时，检索效果能否达到预期？
2. 只有一级章节、没有更深层标题的长 PDF，一级节点的语义导航粒度是否足够？
3. 单个真实章节很长时，一张 RetrievalNode 检索卡能否覆盖该章节的关键主题？
4. 用户使用口语或同义表达、原文使用专业术语时，检索卡向量与 BM25 融合能否定位到正确原文？
5. 回答所需证据分布在多个章节或页面时，受控 Answer 能否读取足够原文并给出正确引用？

## 后续边界

先用当前“真实标题树 + 原文 BM25 + 检索卡向量 + RRF”基线回答以上问题。只有出现明确失败证据时，才比较语义段落、Contextual Retrieval 或 RAPTOR 等替代方案；不因为方案名称多就提前全部实现。
