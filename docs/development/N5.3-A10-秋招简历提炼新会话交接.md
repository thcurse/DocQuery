## 3. 当前真实完成范围

### 3.1 产品链路

- 已有用户登录、应用、API 凭证、知识库、文档版本、处理任务、失败重试和安全删除；
- 管理后台能够完成应用与知识库管理、文档上传和状态查看；
- 已增加知识库问答页面，可选择应用和知识库发起单轮 Answer；
- 支持 PDF、DOCX、Markdown、TXT 经项目内 DeepDoc HTTP 服务解析；
- 原文件与 canonical 产物通过 S3 语义存储，当前本地实现使用 SeaweedFS；
- 文档入库使用 Transactional Outbox、RabbitMQ、租约、分级重试与 DLQ；
- 生成检索卡、Embedding，并将 Evidence/Navigation 双投影写入 Elasticsearch；
- 文档版本只有在整条链路验收成功后才激活，查询固定 activeVersion 快照。

### 3.2 检索与 Answer

- Retrieve 使用 Elasticsearch BM25、Navigation KNN 和 RRF 融合；
- Answer 搜索启用了阿里云百炼 `qwen3-rerank`，并包含应用层覆盖度/多样性排序；
- 单轮 Agent 由 LangChain4j 管理模型和工具循环；业务层控制授权快照、预算、Redis 幂等、审计、
  canonical Evidence 登记和引用校验；
- Agent 可使用 `search`、`open`，并通过 `submit_evidence` 显式结束检索；
- 最终回答采用隔离的 Final Answer Pass，只接收原问题和 Agent 选中的完整证据包，不重放搜索历史、
  工具结果或 Agent 决策，以减少上下文污染；
- 内部 `E#` 只用于证据注册和生成，外部回答转换为用户可理解的文档名与页码引用；
- 当前提示词与策略基线为 `answer-agent-v22 / answer-policy-v22`。

### 3.3 当前模型配置

- Answer：PackyAPI 模型别名 `claude-sonnet-5`，Anthropic Messages 协议；
- 检索卡生成：当前也选择 `claude-sonnet-5`；
- 配置中仍保留 `glm-5.3-flash` Responses 协议 Profile，但不是当前激活的 Answer Profile；
- Embedding：阿里云百炼 `qwen3.7-text-embedding`，2560 维；
- Rerank：阿里云百炼 `qwen3-rerank`；
- 检索卡批次每批最多 4 项，全局有界并发最多 4 个模型请求。

密钥只保存在 `config/application-secrets.yml` 或环境变量中。任何交接、简历和面试材料都不得写出
Base URL 对应的凭证或 API Key。

## 5. 简历可提炼的事实素材

新会话应根据用户投递方向取舍，而不是把所有内容堆进简历。

### 5.1 Java 后端方向

- Spring Boot 4、Spring Security、MyBatis、MySQL/Flyway；
- Transactional Outbox + RabbitMQ Confirm + 分级重试/DLQ；
- Redis 查询幂等所有权、TTL 续租与请求结果复用；
- S3 抽象的对象存储、文档版本状态机、失败重试和安全删除；
- Elasticsearch strict mapping、确定性文档 ID、Evidence/Navigation 双索引投影；
- 有界线程池并行生成检索卡，避免慢模型导致整条入库链路串行阻塞。

### 5.2 RAG / AI 应用方向

- DeepDoc 解析后保留 canonical 原文、标题树、页码和证据位置，而不是只保存无结构 chunk；
- BM25 + 向量 KNN + RRF + Cross-Encoder Rerank 的多阶段检索；
- LangChain4j 高层 Agent 循环与应用层安全边界的混合编排；
- `search/open/submit_evidence` 工具设计、Evidence 注册和最终引用验证；
- 检索 Agent 与 Final Answer Pass 隔离，减少工具历史与无关搜索结果造成的上下文污染；
- Chat Profile 将模型、供应商、协议和密钥配置解耦，已适配 Responses 与 Anthropic Messages；
- 使用冻结问题集、Gold 文档/页面、人工语义复核和失败分类建立可复现评测。

### 5.3 完整 Demo 方向

- React 19、Ant Design、TanStack Query、Vite；
- 管理后台覆盖登录、应用、知识库、文档、处理状态和知识库问答；
- 后端提供受权的 Retrieve/Answer API、审计记录和引用回传，可演示从上传到问答的完整链路。
