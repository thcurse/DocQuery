# N5.3-A4 Answer 最小章节读取

> 状态：`IMPLEMENTED / FREE_REGRESSION_PASSED / REAL_EVAL_NOT_EXECUTED`

## 1. 原因

A3 的 `readSection(documentId, headingNodeId)` 会读取标题的完整 canonical 范围。
父标题范围包含全部二级、三级后代；检索命中 `HEADING_SUBPARTITION` 时又只保留所属
真实标题 ID，导致精确导航范围退化为整章读取。该行为会给模型无关正文并放大输入 Token。

## 2. 当前契约

- 检索与目录工具返回只在本次 Answer 会话有效的 `sectionRef`；
- `readSection(documentId, sectionRef)` 不接受 block、页码或 ordinal；
- `HEADING_SUBPARTITION` 保留检索卡的精确 block 范围；
- 真实叶子标题读取完整叶子章节；
- 带直接子标题的父标题只读取 `block.headingNodeId == 当前标题` 的自身正文，并返回带
  `sectionRef` 的直接子标题；
- 模型仅在问题跨章节时继续读取多个相关子标题；
- PDF 仍按真实标题和物理页聚合 Evidence，用户引用仍为文档、真实标题路径和页码；
- `/retrieve` 的内部读取目标使用 `@JsonIgnore`，不改变外部 HTTP/OpenAPI 契约。

`sectionRef` 是会话内不透明引用，服务端将其绑定到固定 tenant/application/KnowledgeBase、
activeVersion、document、heading 和可选导航范围。模型猜测任意原文坐标不会被执行。

Prompt/Policy 版本更新为 `answer-agent-v4 / answer-policy-v4`。

## 3. 验证边界

- 不重新解析、生成检索卡、Embedding 或索引；
- 不执行 DeepSeek、百炼或其他付费供应商调用；
- 定向测试覆盖父标题不读取子标题正文、导航子分区精确读取、内部目标不进入外部 JSON、
  既有页级 Evidence 与引用行为。
