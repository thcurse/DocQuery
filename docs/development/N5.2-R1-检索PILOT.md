## 1. 阶段目标

只使用“测试科技”租户中已经完成 100/100 READY 的“评测知识库”，通过正式外部 `/retrieve` 契约对预先固定的 10 道可回答题执行小规模真实检索 PILOT。

每道题按相同 `topK=10` 分别执行：

- `KEYWORD`：原文 BM25；
- `SEMANTIC`：检索卡 Query Embedding + KNN；
- `HYBRID`：BM25 与 KNN 经 `retrieve-ranking-v1` RRF 融合。

本阶段共计划 30 个逻辑请求，不调用 `/answer` 或 DeepSeek。

## 2. 固定输入

- 数据集：`mmlongbench-docquery-v1`；
- 语料：P2 已冻结并真实入库的 100 份 PDF；
- 可回答题池：64 道；
- PILOT：10 道，记录在 `evaluation/mmlongbench-docquery-v1/n5.2-r1-pilot-selection.json`；
- 正式保留集：其余 54 道，本阶段不得执行。

PILOT 的确定性选择规则不参考检索结果：覆盖全部 7 个 `sourceDomain`；题量较多的 Research report、Administration/Industry file、Guidebook 各取 2 道，其余领域各取 1 道；域内按 `sourceRowIndex` 升序并保持来源文档不重复。最终覆盖 10 份不同 PDF 和 Int、Float、List、Str 四种答案格式。

## 3. 指标定义

主指标：

1. `Document Recall@5`：Top5 中是否出现 Gold 来源文档；
2. `Evidence Page Recall@10`：Top10 的正确来源文档中，任意 evidence 的 1-based `pageNumber` 是否命中至少一个官方 Gold 页；
3. `MRR@10`：Top10 中第一个正确来源文档结果排名的倒数。

补充诊断：

- `Document Recall@1`、`Document Recall@10`；
- `Evidence Page Coverage@10`：Top10 覆盖的不同 Gold 页数 / Gold 页总数；
- `All Evidence Pages Hit@10`：多页问题的全部 Gold 页是否覆盖。

Document 指标按 `manifest.documentKey <-> response.documentName` 映射；Evidence Page 指标只接受正式响应中的 canonical `sourcePosition.pageNumber`，不使用检索卡摘要或 ES 文本。

## 4. 执行、幂等和失败处理

- 使用专用 Application Credential、READ Grant 和 `knowledgeBaseId=1` 调用正式 HTTP 接口；Credential 只从环境变量读取，不进入报告、命令参数或日志。
- 幂等键固定为阶段版本、caseId 和 mode 的组合；中断恢复复用相同 Key，避免重复昂贵执行。
- `429`、传输超时或 `5xx` 最多自动重试一次；鉴权、参数、数据、资源隐藏和幂等冲突不重试。
- 每个逻辑请求保存外部端到端延迟、HTTP 状态、requestId、queryExecutionId、requested/executed mode、降级信息和脱敏排名结果。
- 原始响应中的 evidence 正文不写入 PILOT 报告，只保存稳定 ID、文档/版本、排名和页码。
- HYBRID 降级必须单独计数；发生降级时不能把该响应标成正常 HYBRID 结果。
- 当前公开契约不返回供应商 Token；本阶段只记录按模式推导的 Query Embedding 调用上限和实际成功/失败/降级，不虚构精确 Token 或金额。

## 5. 报告与验收点

产物位于 `evaluation/mmlongbench-docquery-v1/reports/n5.2-r1-pilot/`：

- `raw-results.jsonl`：30 个逻辑请求的脱敏逐题结果；
- `report.json`：配置、数据指纹、三种模式聚合指标、延迟、失败、重试和降级；
- `report.md`：面向项目展示的简明 PILOT 报告。

R1 只有同时满足以下条件才提交用户验收：

1. 固定 10 道题及选择指纹在执行前落盘；
2. 30/30 个逻辑请求获得可解释终态，无跨租户、历史版本或错误文档映射；
3. 三种模式分别报告，不把降级响应冒充 HYBRID；
4. 三个主指标及补充页覆盖指标经过自动化公式测试；
5. 报告记录真实端到端 HTTP 延迟、失败和重试；
6. 未调用 `/answer`、DeepSeek，未执行其余 54 道；
7. 完成后停止，等待用户确认，不自动开始 N5.2-R2。

PILOT 质量分数不预设及格线。PILOT 后最多允许一次有证据的检索参数调整；是否调整及 R2 的最终冻结参数必须另行确认。
