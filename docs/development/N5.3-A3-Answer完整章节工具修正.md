## 1. 原因

N5.3-A2 证明 Agent 执行可靠性已改善，但错误题中多次出现只取得局部 block、漏掉同页列表项或相邻证据的情况。Answer v2 的 `3 block / 12K 字符 / 60K 字符`读取边界与项目已经冻结的长上下文方向不一致。

## 2. 修正

- 四个只读工具中的 `readDocument` 替换为 `readSection(documentId, headingNodeId)`；
- `headingNodeId` 必须来自当前快照中的检索结果或真实标题树；
- 读取范围严格使用 canonical `HeadingNode.sectionStartBlockOrdinal` 到 `sectionEndBlockOrdinalExclusive`；
- 800K 估算 token 以内的真实章节完整交给 Answer 模型，不再按固定 block 或字符窗口截断；
- 为长章节输入预留时间，单次模型超时调整为 120 秒，整轮 Answer 超时调整为 300 秒；
- 超出本轮剩余安全预算时不创建固定切片，只返回真实直接子标题用于缩小范围；
- PDF 中同一真实标题、同一物理页的连续 block 聚合为一个 Evidence；Markdown、TXT 和 DOCX 按真实标题聚合；
- 模型只看到 Evidence ID、真实标题路径、页码和原文，不再收到 blockId；
- 对外 Answer citation 新增顶层 `pageNumber`，后台显示“文档 / 真实章节 / 第 N 页”；内部 block 与 canonical range 暂为既有 API 兼容和审计保留。

Prompt 同步增加回答前完整性检查：覆盖全部子问题、完成明确算术，并检查选择题证据是否相互矛盾。版本更新为 `answer-agent-v3 / answer-policy-v3`。
