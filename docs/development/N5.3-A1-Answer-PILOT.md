# N5.3-A1 Answer PILOT

> 状态：`PENDING_ACCEPTANCE / COMPLETED_FAILED_ACCEPTANCE`
> 开始授权：用户于 2026-08-23 明确说“确认开始 N5.3-A1 Answer PILOT”。

## 1. 冻结范围

- 从冻结的 N5.2-R3 正式集选取 20 道从未执行 Answer 的公开原题；
- `Str / Int / Float / List` 各 5 题，覆盖 20 份不同来源文档和全部 7 类文档；
- 固定哈希种子和贪心规则只读取题目元数据，不读取 R3 检索结果；
- 调用真实 `/answer`，固定 `HYBRID`、`topK=10`，不传 `documentIds`；
- 不用备用题替换失败题，不自动执行其余 60 题。

## 2. 指标

- 答案：格式感知的自动参考答案匹配，以及 20 题人工正确性复核；
- 引用：正确来源文档、任意 Gold 物理页、Gold 页覆盖率、全部 Gold 页；
- 有据性：人工检查最终回答是否得到所引用 canonical 原文支持；
- 运行：HTTP 成功、Answer 终态、降级、重试、端到端 P50/P95/P99。

验收线固定为：人工正确答案至少 14/20、正确来源文档引用至少 17/20、任意 Gold 页引用至少 13/20、无依据引用 0。

## 3. 成本边界

当前 `/answer` 响应不返回 Token，`DeepSeekAnswerChatAdapter` 也不持久化逐题 usage。本阶段不扩展数据库或外部 API；精确 Token 和费用标记为 `NOT_AVAILABLE`，不根据字符数或模型轮次推算。

## 4. 失败处理与产物

- `429`、传输异常和 `5xx` 最多重试一次；其余错误不重试；
- 固定幂等键并逐题落盘，允许安全中断续跑；
- 保留选择审计、原始脱敏响应、机械评分、人工复核和汇总报告；
- 完成后进入 `PENDING_ACCEPTANCE`，不自动执行其余 60 题或多轮 Agent。

## 5. 真实执行结果

- 20 个逻辑请求产生 31 次 HTTP 尝试：10 个请求成功，10 个请求在一次重试后仍失败，其中另有 1 个请求首次失败、重试成功；
- 21 次失败尝试中，`ANSWER_EXECUTION_LIMIT_EXCEEDED` 15 次，`ANSWER_OUTPUT_INVALID` 6 次；
- 审计累计 63 个工具轮次、108 次工具调用、92 次 Answer 模型调用和 79,814 个登记 canonical 字符；
- 10 个成功请求中，8 个 `ANSWERED`、2 个 `INSUFFICIENT_EVIDENCE`；
- 自动参考答案匹配 5/20；人工按 PDF 原文纠错后正确 7/20；
- 正确来源文档引用 8/20，冻结 Gold 任意页引用 7/20；
- 人工发现 2 个公开参考答案错误和 1 个 Gold 页不完整；这些只作为数据质量说明，不修改冻结输入。

最终验收：`FAILED`。四项门槛均未满足：正确答案 7/20 < 14/20，正确文档引用 8/20 < 17/20，任意 Gold 页引用 7/20 < 13/20，无依据引用 1 > 0。不得执行剩余 60 题。

## 6. 已定位的主要原因

当前 Agent 循环在包括最后一次在内的每次正常模型调用都启用工具。失败审计显示，大量样本在已经完成 3 个工具轮次、进入第 4 次模型调用时仍继续请求工具，于是触发硬上限；另有样本在一次最终结构修复后仍未满足严格 JSON、Evidence ID 或逐行引用契约。该结论是可靠性诊断，不授权自动修改 Answer 策略或追加付费复验。
